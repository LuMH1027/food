调研时间：2026-11-26。基于各产品公开官网与可体验入口整理，聚焦“办公室一人食午餐决策”的业务转化与留存闭环。

## 创业产品级业务闭环

1. **输入减负（场景 + AI）：** 职场人中午很难说清“要吃什么菜”，但能说清状态（例如“下午开会不想犯困，25分钟内送到，不要香菜”）。DeepSeek `deepseek-flash` 将模糊场景转成结构化条件，并给出针对性推荐理由。
2. **安全兜底（AI 与规则分层）：** 大模型负责理解意图和生成自然文案，**不直接绕过硬约束**。忌口、预算上限、少油不炸、主食、昨日主菜去重与“不再推荐”均由本地规则引擎 `sanitizeAiPlan` + `recommend` 强校验，防止模型幻觉漏掉忌口。
3. **正负反馈飞轮：** 支持「☆ 收藏常吃」（后续排序加权）和「以后不推某主菜」（永久屏蔽且可在偏好中恢复），解决单次推荐不准的问题，形成越用越懂用户的留存机制。
4. **单餐到一周的延展：** 把“今天吃什么”延展到“周一到周五怎么吃不重样”，提供锁定、局部替换与 5 天预算汇总，为未来接入外卖平台“工作日午餐包/周期购”留出清晰商业化入口。
5. **贴近履约的最后一公里：** 点击「就吃这份」不仅记录到午餐日记（供次日去重），还自动生成包含忌口和少油要求的外卖备注，一键复制即可直接用于点单。

## DeepSeek 接入与密钥安全

- **本地运行：** `server.mjs` 读取本地 `.env` 中的 `DEEPSEEK_API_KEY`（已加入 `.gitignore`，绝不提交到 Git 仓库），前端通过 `/api/ai/chat` 安全调用 `deepseek-flash`。
- **公开网页（GitHub Pages）：** 静态部署不包含任何硬编码 Key；用户可在页面右上角「接入 DeepSeek」中填入自己的 Key（仅存当前浏览器 `localStorage`，支持测试连通和一键清除）。未填 Key 时自动降级到本地规则，保证任何人点开都能完整体验。
